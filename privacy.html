Privacy Policy

Last updated: November 22, 2026

Jules Shorts is a personal tool used only by its owner to post the owner's own videos to the owner's own TikTok account.

  • Data accessed: basic profile information (user.info.basic) and permission to publish videos (video.publish) for the owner's own account.
  • Data stored: only an access/refresh token on the owner's own computer so uploads work without logging in again. Nothing is collected from other people.
  • Sharing: no data is sold, shared, or disclosed to third parties.
  • Deleting access: the owner can revoke the app at any time in TikTok under Settings and privacy, Security and permissions, Apps and websites.

Contact: via the GitHub profile github.com/julestheguy.
